# WebNest Studio — Free Static Website

A premium responsive agency landing page built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Customize
- Replace `assets/character.png` with your final character image.
- Edit text/content in `index.html`.
- Edit colors and layout in `style.css`.
- Edit interactions in `script.js`.

## Free deployment
This is a static site, so it can be deployed on a free static-hosting service such as GitHub Pages for suitable non-restricted use.

No paid JavaScript library is required.
